프론트엔드 · Chrome

HTML·CSS·JavaScript로 대화와 캘린더를 표시합니다. 브라우저 탭에 최근 대화를 보관합니다.

관리자 인증 · HTTPS→JSON 요청

백엔드 · FastAPI / Uvicorn

start_server.sh가 기존 포트 8000에서 HTTPS로 실행합니다. 현재 공개 주소는 narnialab.duckdns.org:8000이며 관리자 로그인이 필요합니다.

추출하고 저장→결과 반환

데이터 · SQLite

일정을 날짜, 시간, 제목, 분류, 완료 상태로 저장합니다. 프론트엔드는 날짜별 건수를 계산합니다.

백엔드가 연결하는 서비스

대화 API · POST /api/chat

  1. 설정된 Gemini 또는 OpenAI API로 답변과 일정을 추출합니다.
  2. API 키가 없거나 호출이 실패하면 Codex CLI를 시도합니다. 로컬 HTTPS에서 실제 CLI 응답을 확인했습니다.
  3. CLI도 응답하지 않으면 규칙 기반으로 일정과 안내를 생성합니다.

일정 API · /api/tasks

일정 조회·완료·삭제·이월을 처리합니다. 브라우저는 AI나 DB에 직접 연결하지 않습니다.

날씨 API · Open-Meteo

서버가 지역 날씨를 요청하고 기온과 강수량으로 옷차림을 안내합니다. 서비스에 연결하지 못하면 화면에 조회 실패를 표시합니다.

Google Drive API · 실계정 연결 대기

OAuth 승인 후 앱 전용 공간에서 SQLite 파일을 읽고 씁니다. 모의 API로 저장 후 새 앱 실행에서의 복원을 검증합니다.
